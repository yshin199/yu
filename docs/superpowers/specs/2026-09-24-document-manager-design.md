# 本地文档管理桌面软件 — 设计文档

日期：2026-09-24
状态：待用户确认

## 1. 项目概述

一个运行在 Windows 电脑上的**本地桌面软件**，用来管理个人文档/文件和文字备忘。它把"文件整理"和"随手记录"放在一个软件里，用一套分类把它们组织起来。

- **给谁用**：个人自己用（单机、本地）。
- **解决什么问题**：文件散乱难找、没有分类；想随手记备忘和今日计划；希望文件能自动分类、真正整理到文件夹里。
- **成功标准（第一版"算完成"的标志）**：
  1. 双击图标打开软件，有独立窗口，不经过浏览器。
  2. 数据存在本机，关闭、重启电脑后内容不丢。
  3. 能登记文件、建分类（含子分类）、手动分类和自动分类。
  4. 能一键把分类下的文件真正归入对应的电脑文件夹。
  5. 首页能看到今日计划、快速备忘和各模块摘要。
  6. 备忘能写、能分类、今日计划能勾选完成、能搜索和归档。

## 2. 需求与约束

- **运行方式**：Windows 桌面软件（双击图标、独立窗口），不是浏览器网页。
- **本地运行、本地存储**：数据存在当前电脑，刷新/关闭/重启不丢。
- **不联网**：不需要登录、联网、云数据库、部署、手机端。
- **模块**：两个模块——「文档/文件管理」和「备忘/笔记」；外加一个「首页」看板。
- **分类**：有明确的分类，支持自定义分类名称、支持层级（子分类）；文档和备忘**共用一套分类**。
- **自动分类**：按「文件类型」+「文件名关键词（自定义规则）」自动分类。
- **文件管理方式**：两者结合——平时按索引浏览，需要时一键把文件真实归入分类文件夹。
- **今日计划**：归入「备忘/笔记」模块，作为其中一种类型。

## 3. 技术方案

- **桌面外壳**：Electron（Chromium + Node.js），打包成 Windows 安装程序（.exe）。
  - 选它的原因：最成熟、生态最全、界面易做、稳定；能直接读写本机文件和数据库。
  - 备选：Tauri（体积更小、内存占用更低，但需要 Rust 工具链，开发更复杂）。第一版用 Electron 求稳，以后需要再换。
- **数据存储**：SQLite 本地数据库文件，存放在软件的本地数据目录（跟随系统，不受软件重装影响，重启不丢）。
  - 选它的原因：比单个 JSON 文件更适合大量文件的搜索、筛选、排序。
- **界面**：Electron 内的网页界面（HTML/CSS/JS）。

## 4. 数据模型

**分类 Category**：id、名称、父分类 id（空表示顶级）、排序。
**文件条目 FileEntry**：id、文件名、原路径（电脑里的真实路径）、文件类型（按扩展名推断）、分类 id、备注、大小、登记时间、状态（是否已真正归入文件夹）。
**备忘 Memo**：id、标题、内容、类型（普通备忘 / 快速备忘 / 今日计划）、分类 id（可空）、置顶、完成状态（用于今日计划）、归档、计划日期（用于今日计划）、创建/修改时间。
**自动分类规则 Rule**：id、类型（文件类型 / 文件名关键词）、匹配条件（如扩展名 `pdf` 或关键词 `合同`）、目标分类 id、启用状态。

## 5. 界面与模块设计

### 5.1 整体布局

左右两栏：
- **左侧栏（导航）**：顶部三个入口「首页」「文档管理」「备忘笔记」，下方是**分类树**（层级、可展开折叠）。点某个分类可看到该分类下的文件 + 备忘。
- **右侧（内容区）**：随左侧选择变化。

### 5.2 首页

只做"看"和"快速记"，分三块：
1. **今日计划**：列出今天的计划（来自备忘模块），每条有勾选框，点一下完成；顶部输入框回车即新增。
2. **快速备忘**：显示最近几条快速备忘，可一键新增。
3. **各模块摘要**：
   - 文档管理：文件总数、待分类文件数、最近添加的文件。
   - 备忘笔记：未完成的今日计划数、备忘总数、最近备忘。

### 5.3 文档/文件管理

核心模块，功能围绕「登记 → 分类 → 整理」：
- **文件列表**：显示文件名、类型、分类、大小、日期；支持搜索、按类型/分类筛选、排序。
- **导入/登记文件**：把电脑里的文件登记进软件（可单选/多选文件，或扫描整个文件夹，含子文件夹）。登记时**文件本身不动**，只记录路径和分类。新登记的文件默认「未分类」，会出现在首页的"待分类"里，等待手动或自动分类。
- **手动分类**：把文件拖拽或右键归到某分类；同时能新建分类、建子分类、重命名、删除分类。
- **自动分类**：设置规则（按文件类型、按文件名关键词）；执行时**先出预览**（列出每个文件会归到哪），用户确认后才真正分类。
- **一键归入文件夹**：把某分类下的文件**移动**到电脑里对应的分类文件夹（执行前有预览、可撤回）。
- **打开原文件**：双击条目，用系统默认程序打开真实文件。
- **备注**：给文件补充说明文字。

### 5.4 备忘/笔记

功能围绕"写和记"，与文档模块区分开：
- **三种类型**：普通备忘、快速备忘、今日计划。
- **写备忘**：标题 + 正文（纯文本），可归到某分类，可置顶。
- **快速备忘**：像便签，一句话快速记录，不强制写标题。
- **今日计划**：带日期、可勾选"完成"，完成后自动归入"已完成"，不再占用"今日"列表。
- **搜索 / 归档**：按关键词搜索；不用的备忘可归档（不删除，只是收起）。

## 6. 自动分类机制

- **规则来源**：
  - 文件类型：内置默认映射（PDF/Word→文档，jpg/png→图片，xlsx/csv→表格，mp4→视频，zip→压缩包等），用户可增改。
  - 文件名关键词：用户自定义（如文件名含「合同」→归到「合同」分类）。
- **执行流程**：运行"自动分类" → 系统按启用的规则匹配文件 → 弹出**预览清单**（文件 → 建议分类）→ 用户可勾选/改分类 → 确认后生效。
- **安全**：执行前预览、可撤回，避免误分类。

## 7. 关键设计决策

1. 分类支持层级（子分类）。
2. 文档和备忘共用一套分类。
3. 第一版：一个文件/备忘只属于一个分类（不做多标签，以后再加）。
4. "一键归入文件夹"采用**移动**（非复制），且有预览和撤回。
5. 备忘正文先做纯文本，富文本（加粗、列表等）以后再加。

## 8. 第一版范围

**做（第一版）**：
- Electron 桌面程序 + Windows 安装包；SQLite 本地存储。
- 首页（今日计划、快速备忘、模块摘要）。
- 文档管理：登记文件、层级分类（增删改）、手动分类、自动分类（类型+关键词、预览+撤回）、一键归入真实文件夹、打开原文件、搜索筛选、备注。
- 备忘笔记：普通备忘、快速备忘、今日计划（勾选完成）、分类、置顶、搜索、归档。
- 自定义分类名称、层级子分类。

**不做（以后再说）**：
- 多标签（一个东西属于多个分类）。
- 按日期/来源的自动分类。
- 内容识别（读取文件内容、OCR）。
- 备忘富文本、把文件附件挂到备忘上、提醒/通知。
- 云同步、登录、手机端。
- 文件历史版本、回收站。
